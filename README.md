# SolarDiag Pro

Professional, safety-first diagnostics for solar inverters and lithium battery systems.

> Read everything. Change only what is proven safe.

This first runnable Flutter vertical slice provides a responsive battery dashboard backed by a deterministic simulator, honest missing-data handling, and a guarded write policy. It does **not** claim support for real hardware.

```powershell
flutter test
flutter run -d windows
```
