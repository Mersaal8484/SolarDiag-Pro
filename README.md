# SolarDiag Pro

Professional, safety-first diagnostics for solar inverters and lithium battery systems.

> Read everything. Change only what is proven safe.

This repository contains a runnable, safety-first Flutter vertical slice: deterministic BMS simulation, diagnostics, verified-write workflow, inverter–battery compatibility, Protocol Discovery Studio, and a reviewed contribution-platform mock. It does **not** claim support for real hardware or provide a production cloud backend.

```powershell
flutter test
flutter run -d windows
```

Studio and contributions are disabled by default through feature flags. See `docs/FINAL_GAP_REPORT.md` and the generated `docs/CAPABILITY_MATRIX.md` for honest scope and verification status.
