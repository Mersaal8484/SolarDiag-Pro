# Application workspace

The application now uses one responsive workspace: a compact navigation rail on desktop and a bottom navigation bar on mobile. Both select the same indexed pages, preserving state while switching sections.

Implemented sections are Overview, Device Library, Inverter–Battery Link, Gateway, and Parameters. Advanced Diagnostics and Design Lab open as focused routes.

The Device Library distinguishes the bundled simulator from manufacturer research targets. The Link screen is advisory and read-only. The Gateway screen defaults to listen-only and surfaces its transmission allow-list. The Parameters screen exposes simulated values while physical writes remain visibly locked.

Pending UI assembly includes connection onboarding, session history, backup/restore interaction, audit viewer, reports, and detailed fault/history pages.
