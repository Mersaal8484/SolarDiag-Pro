# SolarDiag Symbols

Symbols use a 24×24 grid, 2 pt live-area padding, 1.75 pt strokes, round caps
and joins, and 2 pt corner radii. `design/icons.json` generates the SVG source
set and typed `SolarIcons` catalog. Only icons marked directional mirror in RTL;
waveforms, charts, clocks, and identity marks remain unchanged.
