# SolarDiag design principles

SolarDiag is a calm, precise field instrument. Measurements dominate; chrome
recedes. Layered surfaces communicate depth without decorative shadows. Every
safety state combines text, shape, and an icon, and simulated data exclusively
uses the violet simulated token.

The visual signature is a quiet monochrome instrument surface interrupted by a
single blue interaction tint and the purple simulation mark. The solar gradient
is reserved for the logo, onboarding, and home hero.
