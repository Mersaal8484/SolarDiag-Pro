# Gateway hardware requirements

Software does not validate the physical gateway.

- Isolated RS485 transceiver with direction control, switchable termination/bias and surge/ESD protection.
- Isolated CAN transceiver with listen-only control, switchable 120 Ω termination, standard/extended identifiers and bus-error reporting.
- Protected RS232 level shifter rated for the intended environment.
- Protected 3.3/5 V selectable UART interface.
- Galvanic isolation barriers and isolated power sized and certified for the intended installation category.
- Keyed connectors, documented pinouts, fusing and enclosure clearances.

Required validation includes schematic review by a qualified hardware engineer, isolation/creepage review, EMC/ESD testing, thermal testing, fault injection and model-specific harness verification. High-voltage battery work requires certified service interfaces and qualified technicians.
