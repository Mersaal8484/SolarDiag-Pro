# Protocol coverage plan

All named manufacturers remain research targets. For each target, the owner must obtain an authoritative protocol document with version, firmware applicability, connector/pinout, electrical levels, identification/read commands, telemetry scaling, alarm definitions, and an explicit write procedure before verification can advance.

Priority order for owner review:

1. Select one low-voltage battery family for lawful, read-only hardware validation.
2. Obtain the matching manufacturer communication document and permission to implement it.
3. Acquire an isolated CAN/RS485 gateway prototype and exact connector harness.
4. Capture passively with the manufacturer's original inverter or service software.
5. Confirm identity and telemetry on at least two firmware versions.
6. Treat write verification as a separate safety project with different approver and documented rollback.

Open owner questions: first target manufacturer, exact model and firmware, available documentation rights, test hardware ownership, and qualified approval engineer.
